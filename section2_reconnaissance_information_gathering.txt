2) Obtaining Ip Address, Physical Address using Whois Tool
    a) Active
        ping etf.bg.ac.rs --> send icmp packet to 'etf.bg.ac.rs' using ping and get ip address

        nslookup etf.bg.ac.rs --> we can use nslookup to get the ip of domain we enter

        whois etf.bg.ac.rs --> get info about the domain using 'whois' tool
    
    b) Passive

websites to get ip address

3) Whatweb Stealthy Scan 
    whatweb --help --> to see help options of whatweb commands

    whatweb arh.bg.ac.rs --> use whatweb to scan domain 'arh.bg.ac.rs'

    whatweb arh.bg.ac.rs -v --> with verbose option '-v', the result will be more clean 

4) Aggressive Website Technology Discovering on IP Range 
    whatweb 172.16.1.1-172.16.1.255 --aggression 3 -v --> use whatweb to scan a range of ip with
aggression level and verbose

    whatweb 172.16.1.1-172.16.1.255 --aggression 3 -v --no-errors --> same like above with
no showing errors

    whatweb 172.16.1.1-172.16.1.255 --aggression 3 -v --no-errors --log-verbose=results --> also output
the result into file with name 'results'
